## 能力与交互

注册一个宿主原生工具 `pdf_review`，参数为 `workspace_dir`、`action`、`payload`。

| action | 作用 |
| --- | --- |
| status / help | 检查 Python 依赖，显示中文帮助；不安装软件 |
| list_pdfs | 在明确工作目录中有界发现 PDF，不扫描其他目录 |
| open | 打开指定相对或绝对路径，创建审阅快照，返回页数、表单、页面尺寸和首屏预览 |
| preview | 指定页的 PNG 预览，支持缩放；保留真实 PDF 页坐标 |
| search | 返回文字匹配位置；不将摘要/文本抽取扩展为新交付范围 |
| plan | 按当前 revision 生成候选 PDF、逐项变更说明和受影响页面预览；不替换当前版本 |
| apply | 需要计划 ID、原 revision 和明确 confirmed；验证计划文件哈希后应用 |
| save_as | 导出新 PDF；拒绝覆盖原稿和已有文件；重新打开校验后返回路径与哈希 |

计划支持按文本定位高亮、添加/更新/删除本次审阅创建的批注、填写真实表单字段、放置 PNG/JPEG 图片。
原始 PDF 的已有批注和字段保留。本次新增的文字/图像可从原始快照重新构建，修改和删除不会留下已烘焙内容。
便签采用真正 PDF Text 注释；高亮/下划线/删除线/框/圆采用 PDF 注释；中文印章、自由文字与签名图绘制在页面内容上。
印章和签名图导出后是页面内容，继续修改应保留本次审阅 ID；不承诺任意重开导出文件后可撤销历史叠加。

## 数据与一致性

`.pdf-review/<review_id>/` 保存基准快照、JSON 状态、候选计划和页面预览。
每次修改基于 expected_revision；计划与源快照绑定，应用验证摘要；互斥锁阻止交叉写入。
输入和输出使用解析后的真实路径校验，拒绝 `..`、符号链接/联接逃逸及内部状态目录的输入/导出。
原稿始终保留。导出独立副本，不提供覆盖开关。
不接受 URL/网络图片、任意代码或外部命令；用户先通过宿主把远程材料下载进工作目录。

## PDF 与图像实现

- pypdf：保留文档结构、批注、AcroForm 与字段值，写入并重新打开验证。
- ReportLab：独立绘制中文文字/印章、图片以及表单外观。表单保持可编辑，不以文字叠加伪装填写。
- pypdfium2/PDFium：文字边界定位与页面渲染，不依赖浏览器或查看器会话。
- Pillow：校验图片并保留签名图片比例。
- 依赖为单独安装的 Python 软件包，不重分发其实现或二进制，不自动 pip 安装。提供固定版本 requirements 和可选 WORKSWARM_PDF_PYTHON。
- 原生工具在隔离 Python 子进程中执行，JSON 通过 stdin 传递，不使用 shell；依赖缺失返回中文诊断而不是导致插件加载失败。

## 边界

签名图不属于密码学数字签名。已有有效签名/认证的文件允许查看，但拒绝修改，避免破坏签署结构。
加密文件、歧义字段结构、不支持的控件与越界坐标明确失败；不编造处理成功。
扫描页无可选文字时不能按文本高亮，使用经过用户确认的坐标框选；不增加 OCR 能力。
